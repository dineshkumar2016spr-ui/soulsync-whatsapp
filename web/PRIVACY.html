Privacy Policy

Last updated: 2026-11-05 · Soul Sync

1. Information We Collect

  • Chat content you explicitly import via file or WhatsApp bridge.
  • Consent flags (terms, privacy, readChats, aiAnalysis) and policy version.
  • Session tokens issued after consent (hashed, in-memory, 12h TTL).
  • AI analysis outputs (tone, friction, insights, drafts) generated for the user.
  • WhatsApp session data (auth credentials) stored on the server while connected.

2. How We Use Information

Within the Service
  • Authenticate WebSocket sessions and enforce consent.
  • Buffer chats in memory until you pick which chats to import.
  • Run AI analysis and return drafts/insights.
For AI Providers
  • Only the chat text, the user's name, and the chosen goal are sent to the configured provider (Gemini or OpenAI) when you press "Write drafts".
  • The system prompt instructs the model that chat text is data, not instructions.

3. Data Storage & Retention

  • WhatsApp auth sessions live only while a tab is connected; leftovers are wiped on restart.
  • Consents are written to disk with a policy version and timestamp.
  • Access tokens are hashed and kept in memory with a 12-hour TTL.
  • You can delete your data at any time via "Disconnect and delete my data".

4. Third-Party AI Providers

Your chat content may be transmitted to Google (Gemini) or OpenAI for AI analysis. Their own privacy policies and data-handling practices apply. Soul Sync does not store AI prompts/responses beyond the in-memory handling of the analysis request.

5. Security

Server environment variables hold AI keys and origin allowlists. Data directory should be encrypted at rest on a persistent volume. Sessions use hashed tokens.

6. Your Rights

  • Access / delete your data via the disconnect flow.
  • Withdraw consent via the consent gate.
  • Choose which chats are analysed (pick before import).

7. Children's Privacy

The service is not directed at children under 13/16. WhatsApp's own age requirements apply to the underlying messaging service.

8. Changes

We may update this policy. Continued use after changes constitutes acceptance.
